# Eitus

Veebileht tutvustab Grand Theft Auto mängusarja kõiki osi ajajoone kaudu.

## Veebilehe eesmärk

Leht tutvustab külastajale kõiki GTA mänge. Igal mängul on väljalaskeaasta ja lühitutvustus. Pealehel on interaktiivne ajajoon aastatest 1997–2026. Mängu peale klikkides avaneb selle tutvustus.

## Lehed

- **Avaleht** (`index.html`): GTA ajajoon
- **Ajalugu**: (`ajalugu.html`): GTA ajalugu
- **Maailm**: (`maailmadhtml`): GTA maailmad
